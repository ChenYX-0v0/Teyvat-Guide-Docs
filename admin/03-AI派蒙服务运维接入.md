## 1. 项目概况

「AI 派蒙服务」（teyvat-ai）是「AI 提瓦特向导」拆出的独立模型调用服务，属于主服务之外第一个被拆分的服务。

| 项 | 说明 |
| --- | --- |
| 技术栈 | Python 3.11+ / FastAPI / LangChain + DeepSeek |
| 端口 | 8090（**仅内网/回环，禁止公网暴露**） |
| 对外契约 | `GET /health`（无鉴权）；`POST /v1/complete`（`X-AI-Key` 鉴权）；`POST /v1/complete/stream`（SSE） |
| 状态 | 无状态（不连业务库、不管会话），重启即恢复、可水平复制 |
| 调用方 | 主服务 teyvat-guide（`ai.provider=remote`） |

`GET /health` 响应：

```json
{ "code": 0, "message": "ok", "data": { "status": "up", "version": "0.1.0",
  "extras": { "model": "deepseek-flash", "defaultProfile": "chat", "promptStoreMode": "file" } } }
```

## 2. 接入方式（服务端网关代理）

作为 `managed_projects` 注册表中的一个项目接入，复用统一的网关代理：

```
后台页面 → /api/gateway/teyvat-ai/health → http://127.0.0.1:8090/health
                                          （服务端注入项目凭证，按需）
```

注册表配置：

| 字段 | 值 |
| --- | --- |
| code | `teyvat-ai` |
| name | AI 派蒙服务 |
| base_url | `http://127.0.0.1:8090`（生产内网/HTTPS） |
| auth_type | `header-key` |
| auth_header | `X-AI-Key` |
| health_path | `/health` |
| status | enabled |

> 为支持 `X-AI-Key` 这一非默认头名，`managed_projects` 新增 `auth_header` 列，`applyProjectAuthHeaders` 按该列决定请求头名（默认 `X-Admin-Key`）。

## 3. 本期实现范围（运维管理）

- **服务状态页**：菜单「项目接入 → AI 派蒙服务 → 服务状态」
  - 在线/不可达状态、版本、模型名（取自 health `extras.model`）
  - 走 `/api/gateway/teyvat-ai/health`，凭证不下发浏览器
- 复用了通用组件 `ProjectStatusPanel`（提瓦特向导服务状态页同款），两项目共用一份实现

## 4. 配置项

| 环境变量 | 说明 |
| --- | --- |
| `PROJECT_TEYVAT_AI_ADMIN_KEY` | AI 派蒙服务的 `X-AI-Key`（值 = teyvat-ai 的 `AI_SERVICE_KEY`）；仅服务端使用 |

## 5. 与主服务的关系

```
主服务 teyvat-guide (:8080)  --X-AI-Key-->  AI 派蒙服务 (:8090)  --HTTPS-->  DeepSeek API
```

- 后台对本服务做的是**运维观测**（健康状态），不代理业务聊天请求。
- 主服务侧改造（`ai.provider=remote`、超时/降级）见 `aidoc/doc/03-主服务对接说明.md`。

## 6. 后续可扩展（运维增强）

| 能力 | 说明 |
| --- | --- |
| 健康告警 | 结合 `project_notifications` 机制，对连续不可达记录并提示 |
| 试跑补全 | 后台发一条 `/v1/complete` 验证端到端（会消耗 DeepSeek 额度，需谨慎） |
| 用量观测 | 规格 P4：token/成本按用户与会话统计（需 AI 服务侧提供查询接口） |

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 8090 误暴露公网 | 后台只做状态探测；部署侧禁止公网映射（见 `aidoc/doc/04` §10） |
| 密钥复用 | `X-AI-Key` 独立生成，禁止复用主服务 `X-Admin-Key` |
| 健康检查无鉴权 | `/health` 本就免鉴权，仅暴露 status/version/extras，无敏感信息 |
