## 新项目接入流程（规划）

1. 在 `managed_projects` 注册表登记项目信息（code / base_url / 鉴权方式 / 凭证）。
2. 在网关层确认鉴权适配（header-key / bearer）。
3. 参照 `02-提瓦特向导后台接入设计.md` 的页面结构新增该项目的管理面板。
4. 文档目录下新增该项目的设计文档，编号顺延。
