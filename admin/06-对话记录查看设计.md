## 2. 已定口径（2026-09-12）

| # | 问题 | 决策 | 落地影响 |
| --- | --- | --- | --- |
| 1 | 匿名会话（`user_id=0`）默认隐藏还是显示 | **默认显示** | 不设 `includeAnonymous` 开关，与正常会话同列；用户列显示「匿名」 |
| 2 | 关键词搜索范围 | **只搜提问** | 只匹配 `role='user'` 的 content；**搜索框提示文案必须写明「搜索提问内容」**，否则搜不到回答会被当成 bug |
| 3 | 管理员查看审计 | **暂不做（A）** | 不新建 `admin_audit_log`；升级触发条件见下 |
| 4 | 保留期 / 清理任务 | **先不做** | 不做归档与定时清理，体量小先观察 |

**决策 3 的升级触发条件**：出现**第二个能登录后台的人**时，至少上「B · 只落库」档（后台自有库加 `admin_audit_log`，在拉取会话明细时记一条，约 0.2 人天）。
另记一条**待立项**：**后台权限分级**（审计是"事后可查"，权限分级才是"事前不能看"）。当前所有能登后台的管理员都能看全部用户对话，与 `01` 的"管理员账号 + permission_level"模型是兼容的，但尚未按角色收敛数据范围。**若后台将来开放给非开发人员（运营/客服），必须先做权限分级再放数据**。

## 3. 数据层改动

### 3.1 `chat_messages` 扩列（可空，一次迁移）

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `degraded` | tinyint(1) default 0 | 替代文案比对：列表能筛「降级会话」、能算降级率 |
| `model` | varchar(64) | 本次实际模型（AI 服务 `data.model`） |
| `profile` | varchar(16) | 实际生效档位（chat / analysis / tool / json） |
| `elapsed_ms` | int | 该条回答耗时 |
| `tokens_input` / `tokens_output` / `tokens_cached` | int | **成本必须分开算**：cached 与未命中单价差约 50 倍，只有一个 `tokens` 总数算不出真实成本（`ai/05` §6 P4.2） |

老数据：`degraded=0`、其余为 NULL，不影响既有查询与 `buildHistory`（历史组装只读 `role` / `content`）。

### 3.2 `chat_sessions` 扩列（可选，但建议一起做）

| 字段 | 用途 |
| --- | --- |
| `has_player_context` / `has_asset_reference` | 本会话是否注入过玩家面板 / 资产资料 —— 用于回答「V1/V2 到底有没有用」 |
| `message_count` | 列表页展示轮次，免去每行 COUNT |

### 3.3 索引

| 索引 | 原因 |
| --- | --- |
| `chat_sessions(updated_at)` | 列表默认按会话活跃时间倒序 |
| `chat_messages(session_id, id)` 复合 | 明细按 `(session_id, id)` 游标分页（现有只有 `session_id` 单列） |

> `created_at` 精度是**秒**，同秒多条非常常见，**排序与分页必须带 `id` 兜底**（V2.1 已踩过这个坑：`ORDER BY created_at ASC LIMIT n` 取到的是最旧 n 条）。

## 4. 接口契约（web 侧内网接口）

统一约定：路径**不带** `/api` 前缀；鉴权 `X-Internal-Key`（独立于用户 JWT / `X-Admin-Key` / `X-AI-Key`）；统一信封 `{code,message,data}`，`code === 0` 为成功；**仅内网可达**，密钥不下发浏览器。

### 4.1 会话列表

```
GET /internal/v1/admin/chat/sessions
    ?keyword=&userId=&uid=&onlyDegraded=&from=&to=&page=1&pageSize=20
```

| 参数 | 说明 |
| --- | --- |
| `keyword` | **只匹配提问**（`role='user'` 的 content，LIKE）；体量小先用 LIKE，暂不上全文索引 |
| `userId` | 按 C 端用户过滤（用户管理页「查看对话」跳转带此参数） |
| `uid` | 按游戏 UID 过滤 |
| `onlyDegraded` | `true` 时只返回含降级消息的会话 |
| `from` / `to` | 按 `updated_at` 过滤（RFC3339） |
| `page` / `pageSize` | 默认 1 / 20，`pageSize` 上限 **100**（与 users 一致） |

**响应 data**：

| 字段 | 说明 |
| --- | --- |
| `items[].sessionId` / `title` | 会话标识与标题 |
| `items[].userId` / `username` / `displayName` / `genshinUid` | 归属；匿名时 `userId=0` 且用户字段为 null |
| `items[].messageCount` / `tokens` | 轮次与累计 token |
| `items[].degradedCount` / `hasContext` | 降级条数、是否注入过面板或资料 |
| `items[].lastQuestion` | 最近一条提问的**截断摘要** |
| `items[].createdAt` / `updatedAt` | 时间 |
| `total` / `page` / `pageSize` | 分页元信息 |

排序固定 `updated_at DESC, id DESC`。

> **列表接口不返回消息正文**——避免大 payload，正文只在明细接口取。

### 4.2 会话明细

```
GET /internal/v1/admin/chat/sessions/{sessionId}/messages?afterId=&limit=
```

**响应 data**：`{ sessionId, userId, messages: [{ id, role, content, tokens, model, profile, degraded, elapsedMs, createdAt }] }`

- **游标分页**（`afterId`）而不是 offset：同一会话会持续追加消息，offset 会漂移；
- 默认返回整段（会话通常几轮到几十轮），`limit` 上限 500；
- 会话不存在 → 404。

### 4.3 聚合统计（可选，建议与 P4 可观测合并推进）

```
GET /internal/v1/admin/chat/stats?from=&to=&groupBy=day|user
```

返回问答量、token（**cached / 未命中分开**）、降级率。降级率可直接接入 `03-AI派蒙服务运维接入.md` 的服务健康告警。

### 4.4 错误码

| code | HTTP | 含义 |
| --- | --- | --- |
| 0 | 200 | 成功 |
| 400 | 400 | 参数错误（如 `pageSize` 超上限） |
| 401 | 401 | 缺少/错误的 `X-Internal-Key` |
| 404 | 404 | 会话不存在 |

> **红线：只读。** 不提供修改 / 删除消息的接口——审计数据不可改。要清理只能走运维直接操作数据库。

## 6. 边界与红线

| 项 | 结论 | 依据 |
| --- | --- | --- |
| 记录位置 | **只在主服务**；AI 服务不落库 | AI 服务必须无状态（`shared/01` §1.1） |
| 鉴权 | `X-Internal-Key`，四类密钥各自独立 | `shared/04` §7 |
| 后台**不直连库**读消息 | 聊天记录是用户内容且含聚合语义，属业务实体，应由 web 提供接口；直连仅限低风险读多写少的资产映射 | `shared/04` §3 |
| 日志 | 只记 `sessionId` / `userId` / `tokens`，**禁止把提问与回答正文写进服务端日志** | `AGENTS.md` §4.2 |
| 浏览器 | 密钥只在后台服务端；页面通过 Server Action 取数 | `shared/04` §3 |
| 数据改动 | 只加可空列与索引，不改既有列语义 | `AGENTS.md` §4.4 表结构变更走 `autoMigrate` |

## 8. 验收清单

- [ ] 前端问一句（匿名 + 登录各一次）→ 后台立刻能看到该会话、提问与回答、tokens
- [ ] **流式**回答落库是**一条** assistant 消息，不是多个 delta 碎片
- [ ] 停掉 AI 服务制造降级 → 能筛出降级会话，且能看到已产出的部分内容
- [ ] 关键词只命中提问：搜回答里的词不返回结果（这是既定口径，不是 bug）
- [ ] 匿名会话默认出现在列表里，归属列显示「匿名」
- [ ] 分页正确：同一秒内多条消息不乱序（`updated_at DESC, id DESC`）
- [ ] 明细游标分页在会话持续追加时不错位
- [ ] 缺少/错误 `X-Internal-Key` → 401；浏览器侧看不到任何密钥
- [ ] 服务端日志里没有提问/回答正文
