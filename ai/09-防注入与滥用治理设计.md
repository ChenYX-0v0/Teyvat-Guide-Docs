## 1. 先定损失上限：我们没有"可被滥用的能力"

| 已核实的事实（2026-09-27，逐项读码） | 含义 |
| --- | --- |
| AI 服务与主服务**都没有**工具 / 函数调用 / 代码执行 / 任意 SQL / 文件读写 ✓ | 被穿透的最大损失 = **白嫖一个通用文本助手**（成本 + 合规），**不是**安全事故 |
| AI 服务外网出口只有三处：LLM API、主服务**内网**提示词接口、告警 webhook ✓ | 无法被诱导抓外部内容或外传数据 |
| 用户当前提问走**独立的 user message**（`orchestrator.py:161-164`），未拼进 system ✓ | 最经典的"指令混进系统提示"目前不成立 |
| 参数上限齐全：单条 4000 字、历史 40 条、上下文按 token 裁剪、上游并发 32、超时 55s ✓ | 无法用超长输入做"淹没式"攻击 |

⇒ **主战场是成本与合规，不是"防住入侵"** ✓。方案重心也放这里。

> ⚠️ **长期红线**：AI 服务里已有一个 `tool` 档位定义（`llm/profiles.py`，注释写"P3 LangGraph"）
> 但**尚未接线** ✓。**一旦给模型工具，威胁模型就质变** —— 从"乱说话"变成"乱做事"。
> 将来要上，必须同时具备：工具白名单 + 参数校验 + 审计 + 高风险动作二次确认，并且**单独评审**。

## 3. 分层防御

| 层 | 做什么 | 状态 |
| --- | --- | --- |
| **L0 架构** | 无工具 / 内网 / 无外网 / 管理接口 internal-key；**不给模型工具是长期红线** | ✅ 已具备 |
| **L1 输入侧** | ① 昵称清洗（白名单字符 + 长度 + 注入短语一票否决）② 守卫侧归一化（NFKC + 去零宽/双向控制符） | ✅ 本次上线 |
| **L2 事前短路** | 命中特征 → **不调用大模型**，直接回固定话术（零 token、结果确定） | ✅ 本次上线 |
| **L3 输出守门** | 回复若含系统提示词片段 / 代码块特征 → **整条替换**为固定话术（不是追加） | ⬜ 待实施 |
| **L4 治理闭环** | 分钟级滑窗限速 + 重复消息去重 + 违规计数 → 后台看板 → **人工确认后封号** | ⬜ 待实施（见 TODO-11） |
| **L5 观测回归** | 分类器打开观测 + 红队用例集接 `preflight` | ✅ 观测已开；回归集待接 |

### L2 守卫的判定口径

| reason | 触发 | 回什么 |
| --- | --- | --- |
| `violation` | 反人类 / 反社会 / 反国家 / 反社会主义 / 颠覆分裂 / 恐怖主义 | **【违规发言警告】**话术 |
| `injection` | 忽略指令、套取提示词、角色扮演、越狱/开发者模式（含英文、全角、零宽绕过） | 越界固定话术 |
| `other_domain` | 写代码/调 bug、写周报简历论文、天气财经医疗法律、其他游戏 | 越界固定话术 |
| `emotion` | 现实家庭 / 亲密关系 / 职场 / 心理危机（**与越界同一句话术，但统计分开**） | 越界固定话术 |

**两条刻意的克制**（防止自己变成"过度封锁"）✗：
1. **只做加法，宁漏不误伤**：模式串只收"几乎没有游戏语境"的强特征 ——
   「焦虑 / 压力大 / 迷茫」这类模糊词**故意不收**（玩家会说"抽卡好焦虑"），交给分类器判；
2. **绝不拿模式串去扫 system 文本** ✗ —— 我们自己的规则 21 里就写着「忽略以上指令」这个例子，
   一扫必然误伤。只扫**用户提问** + **字段级**检查昵称。

## 6. 运营开关与回滚

| 开关 | 取值 | 说明 |
| --- | --- | --- |
| `AI_GUARD_ENABLED` | `true`（默认） | 总开关 |
| `AI_GUARD_MODE` | `block`（默认）/ `observe` / `off` | **灰度用 `observe`**：只记日志不拦截，可先观测误伤率再切 `block` |

- 误伤处置：把模式串改细即可（`guard.py` 顶部集中定义 ✓），或临时 `AI_GUARD_MODE=observe`；
- 话术一致性：`tests/test_guard.py::test_fixed_replies_match_prompt` 会断言 guard 的两句话术
  与 `prompts/paimon.json` 逐字一致 —— **改 prompt 忘了改 guard 会立刻红灯** ✓；
- 回滚：AI 镜像回 `teyvat-ai:20260927-1520`、server 回 `20260927-1527` 即为上一版。
