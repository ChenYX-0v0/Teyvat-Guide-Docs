## 维护约定

1. **文档存放位置**：项目文档在本目录（共享仓 `ai/`，项目内为 `doc/`）；跨项目契约在共享仓 `shared/`（项目内为 `shared-docs/`）。
   文档内的代码/配置引用（`app/...`、`../README.md`、`../.env.example`）按 **ai-service 项目视角**书写，通过挂载解析。
2. **契约的唯一权威来源是代码**：
   - 请求 / 响应模型 → `app/schemas/chat.py`
   - 推理档位与参数 → `app/llm/profiles.py`
   - 错误码 → `app/core/envelope.py`
   文档与代码冲突时**以代码为准**，并回来修文档。
3. 改动时的同步关系：

   | 改了什么 | 要同步 |
   | --- | --- |
   | 接口字段 / 错误码 / SSE 协议 | **`shared-docs/01-接口契约.md`**、`../README.md` |
   | 部署方式 / 环境变量 | `../README.md` §4、`../.env.example` |
   | 人格提示词结构 | `02` §4、`../prompts/paimon.json`、`../db/migrations/` |
   | 阶段排期 / 决策 | `05` |
   | 阿里云资源与费用 | `06` |

4. **新增文档后要回来更新本索引**（含上面的「按场景跳转」表），否则索引会腐化。
5. 不要在本目录放临时文档或草稿，用完即删。
