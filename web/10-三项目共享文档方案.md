## 4. 关键实现细节（踩坑记录）

1. **`.ps1` 必须存为 UTF-8 with BOM**：Windows PowerShell 5.1 把无 BOM 的脚本按 ANSI(GBK) 读，中文路径会解析失败（`Unexpected token`）——`setup-docs.ps1` 已转成带 BOM。
2. **`.yaml` 不能带 BOM**：与之相反，Viper 遇 BOM 会静默回落默认值（见 `AGENTS.md` 禁止事项 14）。
3. **Junction 用 `New-Item -ItemType Junction`** 比 `cmd /c mklink` 可靠（后者在 PowerShell 中与管道语法冲突）。
4. **项目 `.gitignore` 必须忽略链接路径**（`/docs/`、`/doc/`、`/aidoc/`、`/shared-docs/`），否则 git 会顺着链接把共享内容当项目文件收录。
5. Junction 是**文件系统特性**，不进 git：新机器 / 新克隆后必须跑一次 `setup-docs.ps1`。
