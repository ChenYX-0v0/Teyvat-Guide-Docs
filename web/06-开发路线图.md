## P1 · 核心能力（大部分已完成 ✅）

- [x] 流式输出（SSE）：`POST /api/chat` 支持 `stream=true`（2026-09-12；主服务透传 + 前端逐字渲染，契约见 `04` §2.2）
- [x] 会话管理：会话列表 / 明细 / 重命名 / 删除（2026-09-12；`GET /api/sessions`、`GET /api/sessions/{id}/messages`、`PATCH /api/sessions/{id}`、`DELETE /api/sessions/{id}`，需登录，契约见 `04` §2.4）
  - 持久化：只对**登录用户**把当前 `sessionId` 存 localStorage 并在进入页面时恢复；**匿名不持久化**（刷新即新对话）
  - 消息一律从服务端拉（不在前端缓存），单屏 100 条、`beforeId` 向上翻页
  - **删除是软删除**（`deleted_at`）：C 端（列表/明细/改名/续聊）从此不可见，**B 端仍可查并标注「已删除」**（`deletedAt` + `onlyDeleted` 筛选）；后台不提供删除入口
- [x] 鉴权健壮性：token 过期/无效时**不再静默降级为匿名**（2026-09-12：`JWTAuthOptional` 对无效 token 返回 401 + 前端启动校验 `/api/auth/me` + 流式请求补 401 处理）
- [x] 用户体系：注册 / 登录 / JWT（无角色区分）
- [x] 玩家档案查询：Enka.Network 数据源 + 映射数据存 MySQL（免登录免风控）
- [x] 账号 ↔ 游戏UID 一对一绑定（绑定前实查验证）
- [x] 推荐词条分级（primary/secondary）驱动前端着色
- [x] 知识库：角色 / 武器 / 圣遗物 / 词条等映射数据表 + 导入脚本（`asset_*` 表 + `cmd/assetimport`，见 `docs/07`）
- [ ] RAG 检索：向量库 + 召回增强回答（当前策略是先做结构化查表，见 `docs/08` §5）
- [x] 资产映射导入（后台 `AssetMappingPanel` → `/api/admin/assets/*`）
- [x] 用户管理（`/internal/v1/admin/users` ↔ 后台 `UserManagementPanel`，契约见 `shared-docs/04`）
- [ ] 翻译缺漏补录页（后台侧 M2-3，见共享仓 `admin/TODO.md` B 段，后台项目内为 `docs/TODO.md`）
