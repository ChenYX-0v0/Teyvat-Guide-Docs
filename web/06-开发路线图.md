## P2 · 体验增强

- [x] **移动端适配（2026-09-14 真机发现问题 → 同日首轮修复完成）**：手机端登录后**完全没有导航**——不是样式问题，是布局层缺入口。下面保留当时的根因记录，便于回溯：
  - **导航缺失（最高优先）**：`Sidebar` 是 `hidden md:block`（<768px 直接不渲染），而 `Header` 里没有任何汉堡/抽屉入口 → 移动端无法在「首页 / 智能问答 / 账号 / 图鉴」之间切换，只能手改 URL。修法：Header 加汉堡按钮 + 抽屉式导航，**复用 `Sidebar` 里同一份 `items` 配置**（避免两套导航漂移），路由变化/遮罩点击/Esc 自动关闭。
  - **历史会话不可达**：对话页的 `SessionList` 是 `hidden md:flex`，移动端看不到会话列表，改名/删除/切换会话都用不了。修法：改成抽屉或底部弹层（复用同一组件与 store），并在对话页给一个明确入口。
  - **Header 小屏拥挤**：副标题（中文较长）应 `hidden sm:block`；昵称 chip 需要 `max-w-* + truncate`。
  - **输入体验**：`ChatInput` 是 `text-sm`（14px），iOS 聚焦输入框会**自动放大页面** → 输入类元素字号应 ≥16px；软键盘下回车是换行键，需确认「回车发送」行为与占位文案。
  - **视口高度**：`AppLayout` 用 `h-full`，移动端浏览器地址栏收起/展开会导致高度跳动或底部被裁 → 建议 `100dvh` + `env(safe-area-inset-bottom)`。
  - **回归范围**：已有 `sm:` 前缀的页面（首页特性卡、图鉴、账号页角色卡）需真机回归；`index.html` 的 viewport meta 已正确（`width=device-width, initial-scale=1.0`），无需改。
  - **已做（2026-09-14）**：抽出 `layout/navItems.ts` 作唯一来源 + `MobileNav` 抽屉（汉堡入口、遮罩/Esc/路由变化自动关闭、开时锁滚动）；`SessionList` 支持 `variant="drawer"`，对话页加「历史会话」按钮（`md:hidden`）；Header 小屏收敛（副标题 `hidden sm:block`、标题/昵称 `truncate`）；`ChatInput` 与登录页输入框改 `text-base sm:text-sm`；`AppLayout` 改 `h-dvh`；首页/登录页小屏内边距与字号收敛。规则已固化到 `02-前端开发规范.md` §5.1。
  - **验证（2026-09-14）**：**真机实测通过**——手机与电脑同一 WiFi 下访问 `http://192.168.3.31:5173`（Vite 已绑 `0.0.0.0`，经其代理打后端 8080 正常），上述 5 条自查项（移动端 ☰ 导航、历史会话抽屉、输入框不放大、底部不被安全区压住、桌面无 ☰）全部正常。
  - **待做**：375 / 390 / 414 三档窄屏仍建议用桌面 DevTools 抽查（本机未装浏览器自动化：Playwright 未安装，未擅自下载）。
