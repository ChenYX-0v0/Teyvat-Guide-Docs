# 05 · 环境搭建与启动

## 1. 前置要求

| 工具 | 版本 | 状态 |
| --- | --- | --- |
| Node.js | ≥ 20（当前 24.14.1） | ✅ 已就绪 |
| npm | ≥ 10（当前 11.11.0） | ✅ 已就绪 |
| Go | 1.27.0（`C:\Program Files\Go\bin`） | ✅ 已就绪 |
| MySQL | 8.4（`127.0.0.1:3306`，root/root） | ✅ 已就绪 |
| Git | 任意 | ✅ 已就绪 |

> Go 由 `winget install -e --id GoLang.Go` 安装，安装程序已把 `C:\Program Files\Go\bin` 写入系统 PATH。
> **注意：已打开的终端不会自动刷新 PATH，需新开一个 PowerShell 窗口才能识别 `go` 命令。**
> 当前模块代理已设为 `GOPROXY=https://goproxy.cn,direct`，依赖已通过 `go mod tidy` 下载完毕。

## 2. 安装 Go（Windows）

方式一：官网安装包（推荐）
1. 打开 https://go.dev/dl/ 下载 `go1.xx.x.windows-amd64.msi`
2. 一路下一步安装，默认会写入 `C:\Program Files\Go\bin` 到 PATH
3. 重启终端后验证：

```powershell
go version
```

方式二：winget

```powershell
winget install -e --id GoLang.Go
```

若 `go version` 提示找不到命令，手动把 `C:\Program Files\Go\bin` 加入系统 PATH。

常用配置（国内加速模块下载）：

```powershell
go env -w GOPROXY=https://goproxy.cn,direct
go env -w GOSUMDB=sum.golang.google.cn
```

## 3. 启动前端

```powershell
cd web
npm install      # 已执行过，依赖已就绪
npm run dev      # http://localhost:5173
```

Vite 已配置代理：`/api` → `http://127.0.0.1:8080`。

## 4. 启动后端

```powershell
cd server
go mod tidy      # 已完成：依赖与 go.sum 均已就绪
go run ./main.go # http://localhost:8080
```

已实测通过（Mock 模式）：

```
GET  /api/health → { "code":0, "data":{ "status":"up", "version":"0.1.0", ... } }
POST /api/chat   → { "code":0, "data":{ "sessionId":"d62b…", "reply":"[Mock] …", "tokens":88, "elapsedMs":38 } }
```

验证：

```powershell
curl http://localhost:8080/api/health
```

## 5. 配置大模型

编辑 `server/config/config.yaml`：

```yaml
ai:
  provider: openai      # mock | openai
  api_key: sk-xxxxxx    # 或用环境变量 TEYVAT_AI_API_KEY
  base_url: https://api.openai.com/v1
  model: gpt-4o-mini
```

使用环境变量（推荐，避免密钥入库）：

```powershell
$env:TEYVAT_AI_PROVIDER="openai"
$env:TEYVAT_AI_API_KEY="sk-xxxxxx"
go run ./main.go
```

未配置密钥时自动降级为 `mock` 实现，接口依然可用，返回占位回复。

## 6. 生产构建

前端：

```powershell
cd web
npm run build          # 输出到 web/dist
```

后端：

```powershell
cd server
go build -o bin/server ./main.go
./bin/server
```

部署建议：前端 `dist` 交给 Nginx / 静态托管；后端用 systemd 或容器运行，Nginx 反代 `/api` 到 8080。

## 7. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 页面显示「未连接」 | 后端未启动 | 启动 Go 服务或检查 8080 端口 |
| `go: command not found` | Go 未安装或未加 PATH | 按第 2 节安装并重启终端 |
| `go mod tidy` 超时 | 网络问题 | 设置 `GOPROXY=https://goproxy.cn,direct` |
| CORS 报错 | 直连 8080 而非走 Vite 代理 | 用 5173 端口访问，或在 `router.go` 增加来源 |
| 端口被占用 | 8080 已占用（常见于旧 server 进程残留） | `Get-Process server \| Stop-Process -Force` 后重启 |
| `Access denied for user` | MySQL 账号密码不对 | 改 `config.yaml` 的 `database.password` 或 `TEYVAT_DATABASE_PASSWORD` |
| `connect: connection refused` | MySQL 服务未启动 | 启动 MySQL 服务后再运行后端 |
