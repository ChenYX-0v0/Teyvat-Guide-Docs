## 2. 安装 Go（Windows）

方式一：官网安装包（推荐）
1. 打开 https://go.dev/dl/ 下载 `go1.xx.x.windows-amd64.msi`
2. 一路下一步安装，默认会写入 `C:\Program Files\Go\bin` 到 PATH
3. 重启终端后验证：

```powershell
go version
```

方式二：winget

```powershell
winget install -e --id GoLang.Go
```

若 `go version` 提示找不到命令，手动把 `C:\Program Files\Go\bin` 加入系统 PATH。

常用配置（国内加速模块下载）：

```powershell
go env -w GOPROXY=https://goproxy.cn,direct
go env -w GOSUMDB=sum.golang.google.cn
```

## 4. 启动后端

> 🔌 **数据库两种接法，别搞混**（`server/config/config.yaml` 指向哪种，应用就连哪种）：
>
> 1. **日常开发**：指向**本机 MySQL**（`127.0.0.1:3306`）。本地跑出来的会话/用量留在本地。
> 2. **需要云端数据或管理接口时**（资产导入、查缺漏、比对线上档案）：起 SSH 隧道 ——
>    它把 **RDS 内网 3306 映射到本机 13306**，并同时给出主服务 18080 / AI 服务 18090 / C 端 9088：
>
>    ```powershell
>    powershell -ExecutionPolicy Bypass -File scripts\tunnel-remote.ps1
>    #   停止：同一条命令加 -Stop
>    ```
>
>    ⚠️ 若报 `Can't connect to MySQL server on '127.0.0.1:13306' (10061)`，说明**隧道已断**（本机起的 ssh
>    会随发起它的终端/会话结束而被回收）—— **重跑一次本脚本**即可，无需改任何配置。
>
>    ⚠️ **2026-10-11 更正**：曾经注册过一个"每 5 分钟自动检查并重建隧道"的计划任务，但**已按用户要求移除** ✗
>    —— 它的动作是 `.cmd`，计划任务交互运行会**弹控制台窗口**，每 5 分钟闪一次很烦 ✓。
>    脚本本身留在仓库里（`scripts\tunnel-watchdog.ps1` ✓，`-Status` 可手动看一眼状态 ✓）；
>    要重新启用**先换掉启动方式**（用 `.vbs` + `wscript` 之类不弹窗的包装 ✓，见主仓 `deploy/README §3.7`），
>    否则弹窗会回来 ✗。⇒ **现在断线仍是"手动重跑一次脚本"** ✓。
>
>    ```powershell
>    powershell -ExecutionPolicy Bypass -File scripts\tunnel-watchdog.ps1 -Status   # 只看状态，不改动
>    Get-Content logs\tunnel-watchdog.log -Tail 20                                   # 看它做过什么
>    ```
>
>    判据是「**经隧道打真请求**」（主服务 `/api/health` 强判据 + AI/前端/RDS 三个 TCP 弱判据 ✓），
>    所以「**进程还在、通道已经死了**」这种假死也能自动救回来 ✓（只看进程/只看端口是抓不到的 ✗）；
>    重建调的就是 `tunnel-remote.ps1`（转发定义只有一份 ✓）。日志与状态在 `logs/`（不入仓 ✓）。
>
>    ⚠️ 只有把 `config.yaml` 改成 `host: 127.0.0.1` / `port: "13306"`，本机应用才会连**生产库**
>    —— 那就意味着**读写都在生产**，用完记得改回本机 MySQL。
>    只想临时连一次、不改文件，可用环境变量覆盖（优先级高于 yaml）：
>    `$env:TEYVAT_DATABASE_HOST='127.0.0.1'; $env:TEYVAT_DATABASE_PORT='13306'`
>
> 只读核查：
>
> ```powershell
> mysql -h 127.0.0.1 -P 13306 -u teyvat teyvat_guide -e "show tables;"   # 口令见本机密钥
> ```
>
> ✅ 已实测（2026-09-26）：隧道通，`mysql` 与项目 Go 代码均可连，RDS = MySQL 8.0.36 / 19 张表。
> ⚠️ 生产库只读排查随时可做，**写数据（资产导入 / 改表 / 刷数据）前先确认**（`AGENTS.md` §7-18）。
> 资产取数与缺漏补齐的完整配方见 `14-游戏资产中文文本获取手册.md` §2。

## 5. 配置大模型

编辑 `server/config/config.yaml`：

```yaml
ai:
  provider: openai      # mock | openai
  api_key: sk-xxxxxx    # 或用环境变量 TEYVAT_AI_API_KEY
  base_url: https://api.openai.com/v1
  model: gpt-4o-mini
```

使用环境变量（推荐，避免密钥入库）：

```powershell
$env:TEYVAT_AI_PROVIDER="openai"
$env:TEYVAT_AI_API_KEY="sk-xxxxxx"
go run ./main.go
```

未配置密钥时自动降级为 `mock` 实现，接口依然可用，返回占位回复。

## 6.5 一键启停（推荐日常用）

仓库 `scripts/` 下有两个脚本，省去每次记端口与启动顺序：

```powershell
# 启动：AI 派蒙服务(8090) + 主服务(8080) + C 端前端(5173)
powershell -ExecutionPolicy Bypass -File scripts\start-all.ps1

# 已经构建过、想快点起（跳过 go build）
powershell -ExecutionPolicy Bypass -File scripts\start-all.ps1 -SkipBuild

# 连后台管理系统（demo-app，3000）一起起
powershell -ExecutionPolicy Bypass -File scripts\start-all.ps1 -WithAdmin

# 停止（默认停 8080 / 8090 / 5173；加 -WithAdmin 连 3000 一起停）
powershell -ExecutionPolicy Bypass -File scripts\stop-all.ps1
```

脚本会做的事：

- **腾端口**：端口被占用时先停掉旧进程，并且**顺着父子链一起停**——AI 服务是 `python(监督) → python(工作，占 8090)`、后台是 `npm → next dev → start-server`，只杀"占端口的那个"会留父进程、干扰下次启动。父进程只在**命令行匹配本项目服务特征**时才停（`app.main` / `vite.js` / `next dev` / `npm run dev` / `teyvat-guide`），不会误伤别的程序；
- **构建**：默认 `go build` 一次（产物落在 `%TEMP%\teyvat-run\`，**不进仓库**），`-SkipBuild` 可跳过（没有产物时会明确提示）；
- **等就绪**：每个服务都有等待与超时，**起不来时自动打印它的日志尾部**，省得自己去翻文件；
- **日志**：统一写 `%TEMP%\teyvat-run\`（`main` / `ai` / `web` / `admin` 的 `.out` 与 `.err`）；
- **收尾**：打印访问地址（含**手机同 WiFi 用的局域网 IP**）与停止命令。

> AI 派蒙服务目录默认指向 `C:\Users\HONOR\Desktop\AI派蒙服务器\ai-service`（它在**另一个仓库**）；换机器用 `-AiServicePath` 指定。
> 前置：MySQL 已运行（脚本会检查并提示）、AI 服务目录下有 `.venv`、`go` 与 `node` 在 PATH 里。

## 7. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 页面显示「未连接」 | 后端未启动 | 启动 Go 服务或检查 8080 端口 |
| `go: command not found` | Go 未安装或未加 PATH | 按第 2 节安装并重启终端 |
| `go mod tidy` 超时 | 网络问题 | 设置 `GOPROXY=https://goproxy.cn,direct` |
| CORS 报错 | 直连 8080 而非走 Vite 代理 | 用 5173 端口访问，或在 `router.go` 增加来源 |
| 端口被占用 | 8080 已占用（常见于旧 server 进程残留） | `Get-Process server \| Stop-Process -Force` 后重启 |
| `Access denied for user` | MySQL 账号密码不对 | 改 `config.yaml` 的 `database.password` 或 `TEYVAT_DATABASE_PASSWORD` |
| `connect: connection refused` | MySQL 服务未启动 | 启动 MySQL 服务后再运行后端 |
