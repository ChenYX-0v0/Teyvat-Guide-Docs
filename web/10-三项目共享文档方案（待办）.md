# 10 · 三项目共享文档方案（待办）

> 状态：**已决策，待实施**（2026-09-11 记录）
> 背景：当前开发需要同时兼顾三个项目 —— **主服务（teyvat-guide）**、**后台运维管理服务**、**AI 派蒙服务**。
> 三者需要共同阅读/修改同一套文档（接口契约、规范、数据表说明等），避免各写一份互相矛盾。

---

## 1. 结论

**采用「独立文档仓库 + 目录 Junction（软链接）」**，配合两条强制规矩。
理由：本机三项目并行开发、一人 + 多个 AI 代理协作，此方案成本最低且 **AI 代理零适配**（它只认项目内的 `docs/` 相对路径）。

---

## 2. 方案对比（记录决策依据）

| 方案 | 做法 | 适合场景 | 代价 | 结论 |
| --- | --- | --- | --- | --- |
| **① 独立文档仓 + Junction** | 一份 `teyvat-docs` 仓库，三个项目根部用 `mklink /J` 挂成各自的 `docs/` | 本机开发、一人 + 多 AI 代理 | 换机器需重建链接（脚本化即可） | ✅ **采用** |
| ② Monorepo | web / 主服务 / admin / AI 同仓，docs 在根 | 长期单仓管理、需 AI 跨项目读代码 | 需调整现有目录结构、仓库变大 | 备选（升级路径） |
| ③ Submodule / Subtree | docs 作为子模块嵌入三仓 | 多人协作、CI 需固定版本 | 工作流繁琐；钉住的是快照而非活文档 | 出现第二人 / 上 CI 时再迁 |
| ❌ 云盘 / 网络共享盘 | OneDrive / 坚果云 / SMB 共享 | —— | 同步冲突、AI 可能读到半同步状态、无版本历史 | 不采用 |

---

## 3. 实施步骤（待执行）

### 3.1 建立文档仓

```powershell
# 方式 A：新起一个仓库
git init D:\teyvat-docs
# 方式 B：把现有 docs/ 提升为仓库（保留历史更佳）
#   git subtree split -P docs -b docs-only   →  再 push 到新仓
```

### 3.2 三个项目建 Junction（**`/J` 不需要管理员权限**）

```powershell
cmd /c mklink /J "C:\Users\HONOR\Desktop\AI提瓦特向导\docs" "D:\teyvat-docs"
cmd /c mklink /J "<admin 项目路径>\docs"  "D:\teyvat-docs"
cmd /c mklink /J "<ai 服务项目路径>\docs" "D:\teyvat-docs"
```

> 换机器 / 新克隆后需重建：把上面三步写成 `setup-docs.ps1` 放在文档仓根，各项目 README 指向它。

### 3.3 更新三个项目的 `AGENTS.md`

在顶部加「文档」章节，明确：

```markdown
## 文档
共享文档目录：./docs/（Junction → teyvat-docs 仓库）
规矩：
1. 只在该目录读写文档；禁止在项目内另建 docs 副本 / 快照
2. 跨项目契约文档（如主服务对接说明）以共享仓版本为唯一来源
```

### 3.4 文档命名与归属约定

| 类型 | 位置 | 命名 |
| --- | --- | --- |
| 跨项目契约（主服务 ↔ AI 服务对接、数据表总览等） | 共享仓根 | `NN-xxx.md`，编号全局唯一 |
| 单项目内部规范（API 文档、前端规范…） | 共享仓根 | 同名文件，用项目前缀或小节区分，禁止三份副本 |

---

## 4. 升级触发条件

| 触发条件 | 动作 |
| --- | --- |
| 出现第二个人参与开发 | 评估迁 ②（monorepo）或 ③（submodule） |
| 需要 CI 自动校验文档 | 迁 ③：CI 里 checkout 文档仓（Junction 在 CI 不可用） |
| 文档需与代码版本严格对应发布 | 迁 ③，按 tag 对齐 |

---

## 5. 验收标准

- [ ] 三个项目内访问 `docs/` 均指向同一份文件（改一处三处生效）
- [ ] `git status` 在三个项目里都不会把 docs 内容当作新增/修改（Junction 不进 git）
- [ ] 三个项目的 `AGENTS.md` 均已声明共享文档入口与两条规矩
- [ ] `setup-docs.ps1` 可在新机器一键重建链接
- [ ] 文档提交只发生在 `teyvat-docs` 仓，其他项目无文档 diff
