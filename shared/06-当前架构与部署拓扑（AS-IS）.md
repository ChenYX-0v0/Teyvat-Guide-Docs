## 3. 一次提问的完整路径（带锚点，便于排查）

| # | 环节 | 细节 | 排查看哪 |
| --- | --- | --- | --- |
| 1 | 浏览器 → 入口 | 备案前：`ssh -L 9088:127.0.0.1:8088` 隧道；备案后：`https://<域名>` | — |
| 2 | Nginx（`web` 容器） | `/api/` 反代 `server:8080`；`proxy_buffering off` 保 SSE；`/api/admin/`、`/internal/` **404** | `docker compose logs web` |
| 3 | 主服务鉴权与闸门 | JWT → 每用户日配额 / 并发闸门（口径见 `05-AI使用边界设计`） | `logs server`：`access` 行 |
| 4 | 资产映射（内存） | 启动时从 RDS 载入：角色 122 / 武器 249 / 套装 65 / **套装效果 120** / 文案 436… | `logs server`：`asset maps loaded` |
| 5 | 玩家上下文 | 有 UID 时调 Enka.Network 取展柜 → 组进上下文 | `logs server`：`ai context attached` |
| 6 | 资料注入 | 按问题关键词匹配资产并拼进提示词 | `logs server`：`ai asset reference attached`（`sets` 字段） |
| 7 | 提示词 | AI 服务 `PROMPT_STORE_MODE=http` → 主服务 `/internal/v1/ai/prompts`（`X-Internal-Key` = `PROMPT_STORE_KEY`） | `logs ai-service`：`prompt_store.backend` |
| 8 | 调 AI 服务 | 主服务 → `http://ai-service:8090/v1/complete`（`X-AI-Key` = `AI_SERVICE_KEY`） | `logs server`：失败会打 `ai complete failed` |
| 9 | 调模型 | AI 服务 → `api.deepseek.com`；命中前缀缓存（`tokens_cached`） | `logs ai-service`：`llm.completed` |
| 10 | 回写与落库 | SSE 逐字回写前端；`chat_messages` / 用量表落 RDS | 前端气泡 + `logs server` |

> **用户看到兜底话术**（"派蒙现在有点晕乎乎的…"）= 第 8/9 步失败：先看 `logs server` 的 `ai complete failed` 的 `err`，再看 `logs ai-service`。

## 4. 后台管理的接入路径（+ 规划）

**现状**：后台跑在本机 3000，**业务项目地址不在环境变量里**，而在管理库 `teyvat_admin.managed_projects.base_url`
（现指向 SSH 隧道 `http://127.0.0.1:18080` / `:18090`）；鉴权密钥走环境变量 `PROJECT_<CODE>_ADMIN_KEY`。
改法、回退与注意点见主仓 `deploy/README.md §3.7`。

**规划（未实施，本轮不做）**：后台**自身也上云**（补 Next.js standalone 镜像 → 只绑回环 → 外层 Nginx 子域 → **管理面必须配访问控制**），
届时 `base_url` 改为容器间地址、**隧道退休**。要点见 `../ai/06-阿里云部署方案.md §1.2`，排期见 `../ai/05-开发路线图.md §8 O5`。

## 5. 端口与暴露面矩阵（公网只应有 22）

| 位置 | 端口 | 服务 | 是否公网可达 |
| --- | --- | --- | --- |
| 云上 ECS | 22 | sshd | ✅（**唯一**对公网开放；建议安全组再限你的固定 IP） |
| 云上 ECS | 8088 / 8080 / 8090 | web / 主服务 / AI 服务 | ❌ 仅 `127.0.0.1`（`docker-proxy`） |
| 云上 ECS | 80 / 443 | 外层 Nginx | ⏳ 备案后开放 |
| 云上 RDS | 3306 | MySQL | ❌ 仅内网 + 白名单（放 ECS 内网 IP） |
| 本机 | 3000 | 后台管理（dev） | ❌ 仅本机 |
| 本机 | 18080 / 18090 | SSH 隧道 | ❌ 仅本机 |
